# Sources and resource register

The academy lessons, manuals, exercises, and field-note articles are original educational material. External books, courses, and videos remain with their authors and publishers. Links are references, not endorsements, sponsorships, affiliate links, or a right to redistribute the linked works.

## What “checked 20 October 2026” means

The linked destinations and topic/title information were checked through public web retrieval or indexed publisher/channel metadata during creation. This is not a claim that every hour of every course was watched, that paid material was purchased, or that an external provider will keep the same URL or terms forever. Two YouTube episode links were confirmed through indexed official channel metadata when direct page retrieval failed.

Cost labels describe the linked resource: free reading/viewing/course material, paid books, or mixed access where stated. Some free courses can require an account, and optional external tools demonstrated within a course can have separate pricing. The academy requires no paid book purchase. No prices, discounts, or subscription entitlements are guaranteed.

Older videos remain useful for concepts, but use current official documentation and the installed package version for commands and configuration. The Playwright documentation is the primary technical reference; publisher pages are the source for book descriptions and legitimate access.

## Resource index

- **[Playwright: installation & first run](https://playwright.dev/docs/intro)** — Playwright team. Documentation; Beginner; Free. The official starting point. Install browsers, run a test, and understand what the runner creates.

- **[Locators that survive UI changes](https://playwright.dev/docs/locators)** — Playwright team. Documentation; Beginner; Free. Learn role, label, text, test ID, chaining, and filtering. Apply one strategy to the Forge Shop catalog.

- **[Assertions and retrying expectations](https://playwright.dev/docs/test-assertions)** — Playwright team. Documentation; Beginner; Free. Choose a web assertion for the outcome you need. Compare a retrying locator assertion with an immediate value check.

- **[API testing with Playwright](https://playwright.dev/docs/api-testing)** — Playwright team. Documentation; Intermediate; Free. Use APIRequestContext for direct HTTP checks, setup, and cross-layer tests. Read this before the cart API exercises.

- **[Fixtures and dependency lifecycles](https://playwright.dev/docs/test-fixtures)** — Playwright team. Documentation; Intermediate; Free. Study test and worker scope, dependencies, and teardown. Build a fixture that owns an isolated lab session.

- **[Authentication and saved state](https://playwright.dev/docs/auth)** — Playwright team. Documentation; Intermediate; Free. Select an authentication strategy that fits shared or mutable server state. Treat saved state as sensitive data.

- **[Trace Viewer: investigate a failure](https://playwright.dev/docs/trace-viewer)** — Playwright team. Documentation; Beginner; Free. Inspect an action timeline, DOM snapshots, and requests. Use a trace to explain a failure before changing code.

- **[Run Playwright in CI](https://playwright.dev/docs/ci)** — Playwright team. Documentation; Intermediate; Free. Official recipes for installing dependencies and running the suite on build infrastructure. Compare with this repository workflow.

- **[Playwright best practices](https://playwright.dev/docs/best-practices)** — Playwright team. Documentation; Beginner; Free. A review checklist for meaningful assertions, robust locators, isolation, and controlled dependencies.

- **[Network control and observation](https://playwright.dev/docs/network)** — Playwright team. Documentation; Intermediate; Free. Observe responses and intercept requests. Practice a controlled server error without damaging the practice API.

- **[Parallelism and independent tests](https://playwright.dev/docs/test-parallel)** — Playwright team. Documentation; Advanced; Free. Understand workers and execution order. Use this when a test passes alone but collides with another test.

- **[Retries and flaky test classification](https://playwright.dev/docs/test-retries)** — Playwright team. Documentation; Intermediate; Free. Learn runner behavior after failure. Use retries to gather evidence while keeping the underlying failure visible.

- **[Visual comparison testing](https://playwright.dev/docs/test-snapshots)** — Playwright team. Documentation; Advanced; Free. Create and review screenshot expectations. Control the rendering environment before accepting baseline changes.

- **[Accessibility testing with axe](https://playwright.dev/docs/accessibility-testing)** — Playwright team. Documentation; Intermediate; Free. Combine automated scans with keyboard and focus checks. Learn the coverage limits of automated accessibility checks.

- **[Projects and browser matrices](https://playwright.dev/docs/test-projects)** — Playwright team. Documentation; Intermediate; Free. Model browsers, devices, or setup dependencies as projects. Keep your feedback loop small before expanding coverage.

- **[Sharding a growing suite](https://playwright.dev/docs/test-sharding)** — Playwright team. Documentation; Advanced; Free. Distribute tests across machines and merge reports. Measure bottlenecks before adding shards.

- **[TypeScript in Playwright](https://playwright.dev/docs/test-typescript)** — Playwright team. Documentation; Beginner; Free. Understand test transpilation and why a separate TypeScript check still matters.

- **[The TypeScript Handbook](https://www.typescriptlang.org/docs/handbook/intro.html)** — TypeScript team. Documentation; Beginner; Free. Read object types, unions, narrowing, and functions. Use types to make test data and helpers harder to misuse.

- **[How to use promises](https://developer.mozilla.org/en-US/docs/Learn_web_development/Extensions/Async_JS/Promises)** — MDN contributors. Documentation; Beginner; Free. Build the async/await foundation needed to understand every Playwright action and assertion.

- **[Introduction to Playwright](https://testautomationu.applitools.com/playwright-intro/)** — Renata Andrade · Test Automation University. Course; Beginner; Free. A compact TypeScript introduction. Recreate each idea against Forge Shop; check older syntax against current docs.

- **[Advanced Playwright](https://testautomationu.applitools.com/playwright-advanced/)** — Test Automation University. Course; Intermediate; Free. Work through API interactions and deeper framework patterns, then apply them to your isolated lab session.

- **[Playwright with JavaScript](https://testautomationu.applitools.com/js-playwright-tutorial/)** — Test Automation University. Course; Beginner; Free. An alternative JavaScript introduction for learners who want to understand browser automation before adding types.

- **[Learn Testing](https://web.dev/learn/testing)** — Google · web.dev. Course; Beginner; Free. A broad testing curriculum to strengthen test design beyond a particular automation tool.

- **[Playwright · Episode 1: Introduction](https://www.youtube.com/watch?v=4-LwodVujTg)** — Visual Studio Code · Microsoft. Video; Beginner; Free. Official YouTube introduction to the testing workflow. Follow it with a first test in this project. Published 2023; verify setup details in current docs.

- **[Get started with end-to-end testing](https://learn.microsoft.com/en-us/shows/getting-started-with-end-to-end-testing-with-playwright/get-started-with-end-to-end-testing-with-playwright)** — Debbie O’Brien · Microsoft Learn. Video; Beginner; Free. Official Episode 2: install the VS Code extension and unpack a first test. Hosted video with chapter markers.

- **[Effective Software Testing](https://www.manning.com/books/effective-software-testing)** — Maurício Aniche · Manning. Book; Intermediate; Paid. Develop systematic boundary and specification-based testing skills. Java examples; principles transfer to this TypeScript project. Publisher purchase/sample page.

- **[Testing JavaScript Applications](https://www.manning.com/books/testing-javascript-applications)** — Lucas da Costa · Manning. Book; Intermediate; Paid. Broaden your understanding of JavaScript test design across application layers. Publisher purchase/sample page, not a Playwright-specific manual.

- **[Unit Testing Principles, Practices, and Patterns](https://www.manning.com/books/unit-testing)** — Vladimir Khorikov · Manning. Book; Intermediate; Paid. Learn to judge the value and maintenance cost of a test. C# examples; use the ideas to question your browser-suite design. Publisher page.

- **[The Practical Test Pyramid](https://martinfowler.com/articles/practical-test-pyramid.html)** — Ham Vocke · martinfowler.com. Article; Intermediate; Free. Use a layered testing strategy to decide which risks deserve browser, integration, or smaller tests.

- **[Playwright Test Agents](https://playwright.dev/docs/test-agents)** — Playwright team. Documentation; Advanced; Free. Current official planner, generator, and healer workflow. Pair this with the academy AI guide and review every changed assertion.

- **[Playwright MCP server](https://github.com/microsoft/playwright-mcp)** — Microsoft · Playwright. Documentation; Advanced; Free. Official browser tooling repository for coding agents. Read current configuration and security guidance before connecting an agent.

- **[Custom instructions with AGENTS.md](https://learn.chatgpt.com/docs/agent-configuration/agents-md)** — OpenAI. Documentation; Intermediate; Free. Official guidance for durable repository instructions. Use the academy prompt pack to define scope, evidence, and review expectations.

- **[Playwright · Episode 3: Running Tests](https://www.youtube.com/watch?v=DcVYaZ8QDsw)** — Visual Studio Code · Microsoft. Video; Beginner; Free. Official YouTube walkthrough of headed and headless execution and the trace viewer. Published 2023; compare UI details with current documentation.

- **[Playwright · Episode 6: Running Tests on CI](https://www.youtube.com/watch?v=gRXPp6RuExU)** — Visual Studio Code · Microsoft. Video; Intermediate; Free. Official YouTube introduction to running Playwright in GitHub Actions. Use the current official CI docs for maintained workflow syntax.
